<task type="auto">
  <name>Task 1: Create ProductConfig interface and supporting types</name>
  <files>src/config/products/types.ts</files>
  <action>
    Create `src/config/products/types.ts` with the following exports:

    1. `interface ProductFeature`:
       - `icon: string` — Lucide icon name (e.g. "Eye", "Shield")
       - `title: string`
       - `desc: string`
       - `cmd: string` — the command shown in a code badge

    2. `interface ProductCommand`:
       - `name: string` — command slug (e.g. "show", "health")
       - `sig: string` — full signature (e.g. "kdm show &lt;target&gt;")
       - `desc: string`
       - `output: string` — the multiline terminal output

    3. `interface ProductStat`:
       - `value: string` — e.g. "12k+"
       - `label: string` — e.g. "Active clusters"

    4. `interface TerminalLine`:
       - `prompt?: string` — shell prompt character
       - `text: string` — line content
       - `out?: boolean` — true for output lines (rendered dimmer)
       - `blink?: boolean` — true for cursor blink on last line

    5. `interface ProductMetadata`:
       - `title: string`
       - `description: string`
       - `ogTitle: string`
       - `ogDescription: string`

    6. `interface ProductConfig`:
       - `slug: string` — route segment (e.g. "kdm", "docker-guard")
       - `displayName: string` — human name (e.g. "KDM", "Docker Guard")
       - `brandName: string` — lowercase brand for nav/footer (e.g. "kdm", "dg")
       - `tagline: string` — headline feature tagline (e.g. "Monitor every pod and container from your terminal.")
       - `description: string` — long description paragraph
       - `version: string` — current version badge (e.g. "v2.4.0 — cloud sync now in beta")
       - `installCommand: string` — the copy-to-clipboard install command
       - `githubUrl: string` — full GitHub repo URL
       - `docsPath: string` — base route path for docs (e.g. "/kdm/docs")
       - `features: ProductFeature[]`
       - `commands: ProductCommand[]`
       - `stats: ProductStat[]`
       - `terminalLines: TerminalLine[]`
       - `ctaTagline: string` — big CTA word (e.g. "Ship." or "Secure.")
       - `ctaDescription: string` — CTA body text
       - `ctaPrimaryText: string` — primary CTA button label
       - `metadata: ProductMetadata`
       - `copyright: string` — footer copyright text (e.g. "© 2026 KDM Labs")

    Do NOT use `ReactNode` or `ReactElement` for the icon field — use string name so configs remain serializable and import-free of React.
  </action>
