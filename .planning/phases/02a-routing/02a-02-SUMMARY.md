# Phase 02a Plan 02: Product-scoped landing pages and documentation routes Summary

Create product landing pages and documentation routes under each product namespace (`/kdm/*` and `/docker-guard/*`), while removing the old flat `/docs/*` routes.

## Changes Made

### Product Landing Pages

**`src/routes/kdm.index.tsx`** — KDM landing page for `/kdm/`
- Route: `createFileRoute("/kdm/")` — renders inside `/kdm` layout's `<Outlet />`
- Component tree: `Navbar > Hero > Features > Commands > CTA > Footer`
- Head metadata sourced from `kdm.metadata` config (title, description)
- All child components get product config via `useProduct()` from the parent `ProductProvider slug="kdm"`

**`src/routes/docker-guard.index.tsx`** — Docker Guard landing page for `/docker-guard/`
- Same structure as kdm.index.tsx but for Docker Guard
- Route: `createFileRoute("/docker-guard/")` — renders inside `/docker-guard` layout's `<Outlet />`
- Head metadata sourced from `dockerGuard.metadata` config

### Product Documentation Routes

**`src/routes/kdm.docs.tsx`** — Documentation layout for `/kdm/docs`
- Route: `createFileRoute("/kdm/docs")` — children of `/kdm` layout
- Sidebar with nav links pointing to `/kdm/docs/{d.slug}` using `docList` from `@/lib/docs`
- `<Outlet />` main content area
- Navbar + Footer wrapping

**`src/routes/kdm.docs.index.tsx`** — Docs index for `/kdm/docs/`
- Route: `createFileRoute("/kdm/docs/")` — child of `/kdm/docs` layout
- Gets doc with empty slug via `getDoc("")`, renders `<DocView />`
- Throws `notFound()` if no index doc exists

**`src/routes/kdm.docs.$slug.tsx`** — Dynamic doc detail for `/kdm/docs/$slug`
- Route: `createFileRoute("/kdm/docs/$slug")`
- Gets doc by slug param, renders `<DocView />`
- Custom `notFoundComponent` referencing `src/docs/kdm/` directory
- Dynamic head with `{doc?.title ?? "Docs"} — KDM`

**`src/routes/docker-guard.docs.tsx`** — Documentation layout for `/docker-guard/docs`
- Same pattern as kdm.docs.tsx with sidebar links to `/docker-guard/docs/{d.slug}`
- Head title: "Docs — Docker Guard"

**`src/routes/docker-guard.docs.index.tsx`** — Docs index for `/docker-guard/docs/`
- Same pattern as kdm.docs.index.tsx
- Head: `{doc?.title ?? "Docs"} — Docker Guard`

**`src/routes/docker-guard.docs.$slug.tsx`** — Dynamic doc detail for `/docker-guard/docs/$slug`
- Same pattern as kdm.docs.$slug.tsx
- notFoundComponent references `src/docs/docker-guard/` directory

### Removed Old Routes

- `src/routes/docs.tsx` — old flat `/docs` layout
- `src/routes/docs.index.tsx` — old flat `/docs/` index
- `src/routes/docs.$slug.tsx` — old flat `/docs/$slug` detail

**`src/routeTree.gen.ts`** — Auto-regenerated by `npm run build`:
- New routes registered: `/kdm/`, `/docker-guard/`, `/kdm/docs`, `/kdm/docs/`, `/kdm/docs/$slug`, `/docker-guard/docs`, `/docker-guard/docs/`, `/docker-guard/docs/$slug`
- Old routes removed: `/docs`, `/docs/`, `/docs/$slug`
- Route hierarchy: `__root__ > /kdm > /kdm/ + /kdm/docs > (/kdm/docs/ + /kdm/docs/$slug)`
- Route hierarchy: `__root__ > /docker-guard > /docker-guard/ + /docker-guard/docs > (/docker-guard/docs/ + /docker-guard/docs/$slug)`
